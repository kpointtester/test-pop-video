KPOINT — fullscreen scroll position test

Checks that the host page returns to the same scroll position after a video goes fullscreen and comes back. Best tested on a real iPhone (Safari) and a real Android (Chrome).

Where to put this file

The videos below belong to Bajaj and only play on domains their account allows, so host this file on the same QA domain their video pages use. Dropping it on an unrelated domain gives a “video not available” error and nothing can be tested.

To test with a different account instead, add its details to the address: ?host=videos.example.com&video=gcc-xxxx. Add &type=silk to force the other player.

How to read the bar at the top
  1. scrollY is how far the page is scrolled right now.
  2. marked is the position we are expected to come back to.
  3. For a popup, the spot is marked automatically when the popup opens.
  4. For an inline video, press Mark this spot before going fullscreen.
  5. The bar turns green when we land back on the marked value, red when we do not.

It is normal for scrollY to read 0 and the page height to shrink while fullscreen is open. Only the value after coming back matters.

4 · Repeat checks

  1. Open a popup, go in and out of fullscreen two or three times, then close it.
  2. Leave fullscreen with the device back gesture / back button instead of the control.

  4. Rotate the phone while fullscreen, rotate back, then exit.
